# Speaking module

`services/speechQueue.ts` schedules speech independently of capture and agent generation. `engines/browser/BrowserSpeakingEngine.ts` uses browser voices, `engines/qwen/QwenSpeakingEngine.ts` uses the Qwen HTTP bridge, and `engines/say/` synthesizes audio on the macOS host. `engines/audio/` plays host-synthesized Say and Qwen audio in the client browser, using the selected client output device when browser output routing is supported. `qwen/QwenSpeakingSettings.tsx` presents engine-specific settings.

Browser and host-audio adapters share `prepare` / `playPrepared` / idempotent `dispose`; preparation is inaudible and playback starts only after coordinator authorization. Browser preparation creates local utterances, not cached synthesized audio; never pre-enqueue future native utterances past silence, pause, or segment-gap gates. Host-audio prefetch applies equally to Say and Qwen. Local `getPlaybackCapabilities` exposes pause/resume mechanics without provider health requests.

`services/sessionSpeechMemory.ts` keeps application-lifetime session cursors and pure pending text checkpoints. `VoiceCoordinator.checkpointSpeech` copies admitted offsets plus the active automatic segment and unread queue; `restoreSpeech` restores logic only while admission is suspended. App composition parks before teardown and restores after preferences and the ownership release barrier. Prepared audio/native resources never enter this memory, and explicit cancellation/global toggle invalidates parked work.

`engines/chatterbox/` adds only a host-audio adapter and a fixed-loopback HTTP job client; it does not change queue or playback policy. `chatterbox/ChatterboxVoiceSettings.tsx` loads the reference catalog without model-health probes. The separately installed local service serializes MLX inference with bounded admission; cancellation discards results at safe generation boundaries, not immediate GPU preemption.

Keep provider adapters separate from conversation policy and DSH composition. Maintain truthful pause/resume capability and distinguish pause from stop/cancel. Abort old operations and prevent stale synthesized audio from beginning after a newer turn or cancellation. Do not let a Settings speech test bypass page-level ownership. Local TTS is an option; it does not imply the DSH model runs offline.
