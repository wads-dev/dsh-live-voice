# Shared design system

`design-system/` contains domain-independent React primitives: buttons, form fields, feedback, layout, and SVG icons. It must never import feature modules or DSH integration. Modules supply translated strings and handlers; shared components only render and dispatch them. Icons use `currentColor` so they follow surrounding text across themes.

Settings layouts include accessible cards, tab navigation, and native disclosure sections. Keep `<details>/<summary>` keyboard behavior and ARIA semantics when changing a subsection; headings and icons should not become separate unlabeled controls. Shared primitives should not own persisted settings, product policy, or translation catalogs. `SettingsSectionBody` owns the standard content inset below section headings. `Hint` provides keyboard-, pointer-, and touch-accessible help in the browser top layer rather than native title tooltips. Settings explanations and instructions must use these tooltips, never persistent paragraphs or repeated helper lines; consolidate section-wide help into one heading tooltip. Keep actual status and actionable errors visible. `PhraseField` renders editable command lists as removable tokens while retaining uncommitted text locally. The settings composition keeps its conditional debugger launcher outside the scrolling content viewport. `forms/DraftField.tsx` centralizes local raw editing for text, textarea, and numeric controls. Consumers use `onCommit` for normalization and persistence on blur; parent updates must not replace active drafts. Invalid numeric drafts restore the saved value on blur.

`feedback/ContextPopover.tsx` provides interactive top-layer context panels. Normal click preserves the trigger’s primary action by default, as used by microphone/speaker controls; `openOnClick` is an explicit opt-in for the meeting source menu. Context click and ContextMenu/Shift+F10 open the same panel, Escape restores trigger focus, and outside pointer/focus closes it. Panel and anchor resize observation repositions growing forms and feedback within viewport margins; capped height remains scrollable and observers are disconnected on close. The primitive never starts capture or meeting operations itself.
